# Prototype guide

TCG Frame Generator helps you arrange existing trading cards, find the required frame size, and export a placement template. It does not create card artwork.

1. Choose a card format and quantity, then click Add cards.
2. Adjust columns, card spacing and border spacing. Automatic frame sizing follows your layout.
3. Click a card to edit its size. Hold Ctrl or Cmd to select several cards. Press Delete to remove the selection.
4. Enable Free placement under Advanced arrangement to move cards manually.
5. Clear all resets the display to an empty project. Add cards to start again. Undo restores the previous project.
6. Save your project or download the SVG template. Print at 100% and check the measurements before cutting.

Frame sizes are inner dimensions. Slab sizes are approximate. Measure your holders before ordering a frame. PDF printing uses the full layout size; tiled printing requires another application.

Open index.html locally, or publish the repository root with GitHub Pages.
