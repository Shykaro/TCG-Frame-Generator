# TCG Frame Generator

A browser-only TCG display planner, ready for GitHub Pages. No build step, dependencies, or uploads.


## Removing cards

Use **Clear all** below the canvas to remove every card. Select one or more cards (Ctrl/Cmd + click) and press **Delete** or use **Delete selected** in the inspector. Delete does not remove cards while editing a text or number field. Both operations can be undone.

## Search identity

The page title, main heading, description, social metadata and WebApplication structured data identify the product as a TCG Frame Generator for display frames and passepartout templates, not a custom card artwork generator. No canonical URL is hardcoded until the final production domain is confirmed.
